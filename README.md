# 량원펑 신격화 게이지

31단계 슬라이더. 기본 시작은 신격화(+15). 크게 보려면 iframe 자체 높이를 넉넉하게 설정해야 합니다. 권장 크기 PC 440×440px / 모바일 가로 100%·높이 440px (이미지 최대 248px). 기존 280×190 또는 320×250 iframe은 부모 문서에서 크기가 고정돼 있으므로 자동 확대되지 않습니다. 아카라이브에서 iframe 저장·새로고침 후 동작 여부는 별도 확인이 필요합니다.

- 량붕이: 대체 신모델 언제나옴?
- 량통수: 이걸 신모델이라고 내놓음?
- 량원펑: 일단 중립기어 박아봄
- 대원평: 명불허전이죠? 대가리 다 봉합됐죠?
- 갓원평: 그저 GOAT
- 킹갓평: 예수, 왜 회의를 시작하지 않는거지? / 아직 량원펑이 오지 않았다네.

## 임베드

```html
<iframe src="https://kimrinking-cell.github.io/liang-compact-ko/?layout=v3" width="440" height="440" style="border:0;width:100%;max-width:440px;height:440px;" title="량원펑 슬라이더"></iframe>
```

원본 코드 참고: https://github.com/Lichtspektrum/liang-intensity-calibrator (MIT). 원본 초상 이미지·영상은 별도 라이선스로 공개 저장소에 재배포하지 않고 원본 GitHub Pages에서 불러옵니다. 이미지 사용 권한은 별도로 확인할 필요가 있습니다.

기본 시작 위치는 신격화(+15, 킹갓평)이며 `?score=0`으로 시작 단계를 지정할 수 있습니다.

모바일에서도 최대한 크게 보이려면 게시글 HTML의 iframe `width`와 `height`도 변경하세요. 기존 링크의 캐시가 남는 경우 `?layout=v3`로 새 URL을 사용합니다.

슬라이더를 이동해 문구가 바뀌어도 위젯의 높이는 440px로 고정됩니다.
